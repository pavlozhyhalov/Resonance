# Вичитка es / fr / de — супровідні нотатки до `SITE-TEXT-AUDIT-es-fr-de.csv`

Дата: 2026-08-24. Відповідає на ТЗ «аудит es/fr/de + звірка рішень».

## 1. Що таке `SITE-TEXT-AUDIT-es-fr-de.csv`

Повнотекстовий дамп **усього UI-тексту** трьома новими мовами для ручної
мовної вичитки (не статистика). Колонки: `source, key/id, uk, es, fr, de, note`.

| source | рядків | що це |
|---|---:|---|
| `dict` | 1286 | ключі `i18n/{es,fr,de}.json` (uk-колонка = сам ключ) |
| `rsT` | 89 | інлайн-блоки `__rsT({…})` у бандлі; `key/id = rsT#N` за порядком появи у файлі |
| `pattern` | 62 | `i18n/patterns.json`; uk-колонка = regex `p`, що матчить зібраний uk-рядок; `$1..$4` — плейсхолдери |
| `exercise` | 60 | картки кардіо/силових (по 6 полів × 10 вправ: `t, tag, info, b×3`) |
| `privacy` | 19 | обʼєкти Політики приватності (`upd` + 9 секцій × `h/p`) |
| `gemini-directive` | 3 | точний текст мовної директиви до Gemini (edge `assistant v12`), по мові |
| `gemini-langdir` | 1 | мовні мітки клієнтського префікса контексту `__rsLangDir` |
| `gemini-limitmsg` | 1 | доброзичливе повідомлення про rate-limit (показується в чаті) |
| **Разом** | **1521** | |

Примітки до читання:
- Рядки з конкатенацією показані «як є» з підстановкою змінної, напр.
  `rsT#3`: uk `"ще "+diff+" дн"` → es `"quedan "+diff+" d"` → de `"noch "+diff+" T"`.
- `gemini-directive` навмисно однокольонковий (текст лише у своїй мові) — це
  системний промпт, а не UI.
- Порожніх клітинок es/fr/de серед UI-рядків: **0**.

## 2. «Оступ» → «осечка» (ru): повний перелік місць — для рев'ю власника

> **Статус процесу.** За записами попередньої сесії це питання (P1.5) було
> винесене окремо й отримало відповідь **«Перекласти на Осечка»**, тому зміну
> застосовано. Якщо це не збігається з наміром — відкат тривіальний (нижче
> точний перелік). uk **не** чіпалося (лишається «оступ»); pl лишилося
> «Potknięcie/Potkn.»; en — «Slip». Змінено **тільки ru-значення**.

**A. `app.bundle.js` — 6 блоків `__rsT` (одне з них у 2 місцях коду → 7 входжень):**

| uk (незмінно) | ru: було → стало |
|---|---|
| `Оступ` (повна форма, pl `Potknięcie`) | `Оступ` → **`Осечка`** |
| `Оступ` (компактна, pl `Potkn.`) | → **`Осечка`** |
| `Оступ ✓` | → **`Осечка ✓`** |
| `Оступ +1` | → **`Осечка +1`** |
| `Ліміт оступів — зараховано зрив` *(×2 у коді)* | → **`Лимит осечек — засчитан срыв`** |
| `Познач дні, коли був зрив або оступ. Решта — успішні.` | → **`Отмечай дни срыва или осечки. Остальные — успешные.`** |

**B. `docs/APP-STORE-LISTING.md` (рядок ~134, RU-опис):**
`Привычки: чисто · осечка · срыв. Одна случайная осечка не обнуляет серию сразу…`
(тут «осечка» вжито 2×).

> Цих рядків **немає** у `i18n/ru.json` — стан звички зберігається лише в
> блоках `__rsT` (джерело істини за глосарієм), тому в словниках ru «осечки»
> нема й бути не повинно.

## 3. Закриті питання (підтверджено власником у ТЗ)

- **Демо-імена спільноти (Марія / Богдан / Софія)** — варіант **(a): лишити
  кирилицею**. Змін не вносив, питання закрито. (Автозаміна через словник була б
  небезпечною: `__rsTr` робить глобальну заміну текст-нод, тож реальний
  користувач із таким іменем побачив би своє імʼя зміненим.)
- **Німецькі «Serie» / «Level»** — лишити без змін. Відповідає початковому глосарію.
  Змін не вносив, питання закрито.

## 4. Підтвердження щодо «безпечних» залишків кирилиці (одне речення)

Підтверджую: **`uk:`-поля 7-мовних обʼєктів і контекст-промпти до Gemini
(профіль-зведення на кшталт «стать чоловіча», події-підказки, `__rsLangDir`)
ніколи не рендеряться користувачу як UI** — `uk:`-поле повертається лише коли
активна мова = uk (це база для україномовних), а промпт-контекст іде в тіло
запиту до edge-функції `assistant`, а не в DOM.
